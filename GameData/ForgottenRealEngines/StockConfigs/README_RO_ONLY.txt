Brazilian Engines / ForgottenRealEngines is maintained here as an RSS+RO+RP-1-only package.

The original stock KSP configs in this folder have been renamed to .cfg.DISABLED so they do not load in a Realism Overhaul install.
They used stock resources such as SolidFuel, LiquidFuel and Oxidizer, which are intentionally avoided in this project.

Use GameData/ForgottenRealEngines/ROConfigs instead.
