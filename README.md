# BrazilianEngines - Mod for KSP RP-1

**BrazilianEngines** is a mod for *Kerbal Space Program* with *Realism Overhaul* and *RP-1*, which adds a collection of Brazilian rocket engines, real and fictional, powered by liquid and solid propellants, inspired by Brazil's space program.

## About the Mod

BrazilianEngines brings engines inspired by Brazil's space program, combining historical designs with fictional creations that celebrate Brazil's aerospace potential. This is a version in development that seeks to honor the legacy of the national space program and, in particular, the 21 heroes of Alcântara.

This mod is designed to work with *Realism Overhaul* and *Real Solar System*, offering a realistic space exploration experience in KSP.

## Features

### Included Engines

#### S-Series (Solid Motors)
- **S10-1, S10-2** - New low-thrust engines
- **S20, S23** - First generation engines
- **S30, S31, S33** - Second generation engines
- **S40, S43, S44** - Third generation engines (VLS-1)

#### Future Engines (In Development)
- Liquid Engines: L5, L15, L75
- MLBR Program: N04, N09, N90 and Arion liquid engine

### 3D Models
- Custom 3D models for all S-series engines
- Progressive reduction of third-party dependency

## Dependencies

To use BrazilianEngines, you need the following mods installed:

- **ROEngines** - Provides base models and reference configurations
- **Realism Overhaul** - Adds realism to KSP
- **Real Solar System** - Realistic solar system

## Installation

1. Download the latest version of the mod from the [releases page](https://github.com/Cross-Space/BrazilianEngines/releases).
2. Extract the `.zip` file and copy the `BrazilianEngines` folder to your *Kerbal Space Program* `GameData` folder.
3. Make sure all dependencies listed above are installed correctly.
4. Launch KSP and enjoy the Brazilian engines in your missions!

## Current Status

This is an actively developed project. Version 1.2.0+ includes:

- ✅ S-series solid engines with custom 3D models
- ✅ Integration with RSS CommNet (Sites_RSS.cfg)
- ⏳ Full integration with RP-1 technology tree
- ⏳ Brazilian liquid engines (L5, L15, L75)
- ⏳ 3D models for all engines

We are working to improve the mod with more accurate descriptions, complete history of Brazilian space programs, and additional resources based on real projects.

This mod is dedicated to the **21 heroes of Alcântara**, whose lives were lost on August 22, 2003, in pursuit of advancing Brazil's space program. Their sacrifice inspires this project and our mission to celebrate Brazil's aerospace history.
